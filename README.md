# Weblet Privacy Policy

Simple React page for the Weblet Privacy Policy (Play Store / in-app link).

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deploy the `dist/` folder to any static host (GitHub Pages, Netlify, Vercel, Firebase Hosting, etc.), then put that URL in Play Console and in the Weblet app Settings → About.

## Customize

- Contact email: `CONTACT_EMAIL` in `src/App.jsx`
- Effective date: `LAST_UPDATED` in `src/App.jsx`
